# libya-parallel-knowledge-layer
a small, ethical, Arabic-first prototype that collects, organizes, and searches public and parallel knowledge content for government services or education.
# Libya Parallel Knowledge Layer (LPL)

منصة تجريبية لتجميع وتنظيم والبحث في محتوى وبيانات موازية عامة، بهدف دعم الخدمات الحكومية الرقمية والتعليم في ليبيا.

## الهدف البحثي

بناء نموذج أولي منخفض التكلفة يمكن قياسه وتوسيعه لاحقًا، دون الاعتماد على بيانات شخصية أو سرية.

## النطاق الأولي

- تجميع محتوى عام موثق المصدر.
- تصنيف المحتوى حسب القطاع ونوع المعلومة.
- البحث العربي في العناوين والملخصات والنصوص.
- عرض المصدر الأصلي وتاريخ النشر ودرجة الموثوقية.
- السماح بالإبلاغ عن محتوى قديم أو غير دقيق.

## التقنيات

- Next.js
- React
- TypeScript
- Tailwind CSS
- SQLite في النسخة التجريبية
- PostgreSQL عند التوسع

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح المتصفح على:

```text
http://localhost:3000
```

## ملاحظة أخلاقية

هذه المنصة ليست بديلاً عن المصادر الرسمية. كل محتوى يجب أن يعرض مصدره الأصلي وتاريخ نشره وتاريخ آخر تحقق.
